# CLONE v0.1.0 — source/dependency record

CLONE simulation/UI/model/texture/audio source in this package is original project work created for
DEV. RSA/DEV retains control of its distribution terms; this record makes no new license grant.
The compact renderer was adapted from the original RSA Studio polygon renderer built in this
conversation; no old workspace, operators, provider keys or project data are included.

Reference photographs were used to guide materials and miniature proportions; they are not shipped,
traced into textures or redistributed. No Yo-kai Watch, Digimon or Project Zomboid assets, characters,
code, logos or proprietary material packs are used. They were style/performance references only.

Runtime: browser JavaScript, DOM, WebGL2, localStorage and Web Audio. Optional localhost host uses
Node built-in http/fs/path/child_process modules. Node is not bundled. No third-party game engine,
model CDN, paid AI API or login is required by this game base.

External sites/YouTube remain subject to their own availability and embedding/service terms.
Their content is not bundled. Audio effects are generated locally from bounded oscillators/noise.
Tests use Node built-ins; native graphics verification uses system Mesa/EGL, Python, numpy and
Pillow. Playwright and system Chromium were used only for an attempted browser acceptance check;
launch was blocked. These developer dependencies are not bundled runtime requirements.
