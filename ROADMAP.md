# CLONE — incremental milestones

1. Home 01 foundation: dream identity, wake, room scale, ground placement, usable household models,
   local saves/log, time/weather and starter neighbor encounters. Current v0.1 checkpoint.
2. Actual target-device browser/audio acceptance; improve the authored assets against the locked
   photographs using actual in-game renders. Establish representative dense-room frame/VRAM budgets.
3. Layered supports and stacking, walls/doors/windows, validated stairs/loft navigation, richer physics
   and water. Geometry and occupancy must evolve together; no decorative inaccessible floor levels.
4. Neighbors with persistent schedules/relationships and bounded event threads, needs/economy,
   broader meaningful consequences, archive journal chunks and save migrations.
5. Streamed modern Japanese neighborhood chunks, entrances/interiors, community and weather detail.
6. Evaluate a real embedded browser/runtime for the game computer, with explicit resource/privacy
   controls and OS/program boundaries. Do not silently convert the current iframe into that claim.
7. Multiplayer only after an authoritative server, validated actions, ownership/inventory rules,
   disconnect/reconnect state, account/save boundaries and abuse/resource limits are implemented.

These are development directions, not promises of features already present in the downloadable base.
